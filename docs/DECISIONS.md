# Décisions — Namesia

Les décisions sont révisables ; une révision doit expliquer le contexte et les conséquences.

## D-001 — Next.js App Router, React, TypeScript
**Statut : adopté pour le socle.** Choisi pour le rendu, le SEO et l'intégration Vercel. Alternative : React/Vite pour une SPA plus simple. Challenge : réévaluer si les besoins de rendu serveur ne justifient pas la complexité de Next.js.

## D-002 — Pas de bibliothèque UI au départ
**Statut : provisoire.** Le CSS suffit pour valider l'expérience initiale. Comparer à nouveau si le nombre de composants et les besoins d'accessibilité augmentent.

## D-003 — Supabase comme base prévue
**Statut : prévu, intégration non réalisée.** Concevoir le modèle éditorial et les sources avant de figer le schéma.

## D-004 — Données de démonstration locales
**Statut : adopté pour le prototype.** Les exemples sont explicitement signalés et devront être remplacés par un flux de données fiable.
