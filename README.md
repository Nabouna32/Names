# Namesia

Namesia est un site de découverte des prénoms : des informations culturelles précises et un univers symbolique chaleureux pour explorer au-delà d’une simple recherche.

## Développement
Prérequis : Node.js 24+ et npm.

```bash
npm ci
npm run dev
```

Vérifications : `npm run lint`, `npm run typecheck`, `npm run build`.

Site de production : [namesia.vercel.app](https://namesia.vercel.app).
